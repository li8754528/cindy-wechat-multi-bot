# Cindy 微信伙伴

一个 Cindy 插件管理多个微信 Bot；每个 Bot 固定对应一个不同的伙伴。插件负责微信文字与图片收发，伙伴负责回答，也可按主人要求主动发送通知。收到语音时，插件直接提示先在微信转成文字再发送。

## 开发

需要 Node.js 22。开发阶段执行 `npm ci --ignore-scripts`、`npm run build`、`npm test`、`npm run check`。构建产物在 `wechat-companion/`；依赖已打进 Node 工作进程，用户安装插件后不需要运行 npm。由 Cindy Forge 打包为 `.cindy`。

最低目标宿主 Cindy 0.1.128。源码按正式 tag v0.1.128 / commit `9d62b213c960c63daa46996de8a606965f2f2299` 核对接口，不依赖客户端私有 IPC。

## 首次使用

安装后打开“微信伙伴”的设置页或“使用”面板，点击“＋ 新增 Bot”立即获取二维码，用微信扫码并确认。登录成功后填写 Bot 名称、选择一位伙伴，点击“开始聊天”即可使用；继续点击“新增 Bot”可连接另一个 Bot。每个 Bot 独立显示状态、回答伙伴和收到/回复计数，聊天中可一键暂停或恢复，无需寻找启用开关。扫码后暂未选择伙伴的登录也会保存，重新打开后点击卡片的“选择伙伴”继续。收到的消息直接投递给已选伙伴，沿用伙伴自己的模型与权限，插件没有模型选择，也不创建额外任务。伙伴调用 `reply_to_wechat` 回传本次答案。

Bot 与伙伴一对一；同一个真实 Bot 账号不能登录到两组配置，也不要同时用于 Cindy 内置连接与本插件。同一 Bot 的消息依次处理，仅当前请求可以回传；不同 Bot 可独立工作。伙伴原有权限保持不变，需要主人处理的请求仍在 Cindy 中处理。

0.3.2 起，伙伴消息正文只显示微信用户原文，没有“来自微信”前缀、逐条请求编号或折叠的附带资料；图片附件保持原有交接方式。来源由宿主单独标记“由插件「微信伙伴」发送”，模型收到对应的 `[消息来源]`，插件不伪造来源文字。0.3.3 起，语音消息由插件直接提示转换后重发，不转交伙伴。

绑定保存后会单独发送一次回传规则说明。重复保存、改名、暂停/恢复和重启不重复发送；换绑伙伴则发送新说明。插件只要求伙伴记住，不保证已写入长期记忆。旧绑定升级后不会自动联系伙伴：请在 Bot 卡片点“发送伙伴说明”，或编辑该 Bot 并保存。说明处理成功的回执确认后才派发微信请求；说明正常处理中会暂存本次输入，等待计时预算一分钟（包含查询耗时），完成后继续派发；缺少/失败/未知说明或等待超时也会进入转交重试计划；请在等待期间按卡片提示处理说明。重试耗尽后明确拒绝，请在微信重发。处理状态可以“刷新状态”查看，失败用“核实并重试伙伴说明”显式恢复；投递未知先查询原请求键，不盲目换键重发。说明本身不是微信请求，没有当前请求时回传工具会拒绝。

0.3.4 起，文字和图片转交伙伴失败时，等待 3 分钟自动重试一次；仍失败则再等待 10 分钟重试一次，最多首次加两次重试。重试沿用相同请求编号、文字、图片和伙伴，不重复创建请求；成功即停止。同一 Bot 的后续消息继续排队，不同 Bot 不受影响。刷新面板可查看下一次重试时间和次数。停用、换绑、连接/工作进程重置或请求过期取消重试；授权拒绝、接口不支持及无效请求不自动重试。重试耗尽显示 DISPATCH_RETRY_EXHAUSTED，投递仍不确定显示 DISPATCH_DELIVERY_UNCERTAIN。重试只保存在内存，重启不恢复；微信端回复和语音提示的未知发送仍不自动重发。

伙伴仍须在本轮结束前调用 `reply_to_wechat`，仅在伙伴对话里写出答案不会自动同步到微信。现在可省略 `request_id`，由宿主校验的伙伴会话身份查找唯一绑定和当前有效请求；无当前、歧义、过期或错误身份都会拒绝，不接受 Bot 或收件人。显式编号仍兼容。同一工具 callId 的重复调用锁定原请求和原拒绝结果，不能因排队消息推进改投下一条；更换 callId 的过时调用仍可能误用当前请求，无法仅凭 canonical 会话身份和一次说明消除这一残余风险。

宿主提供请求完成回执时，插件按原 requestKey 查询，只关闭已结束且尚未开始回传的请求，并释放本组排队占用；按已确认的完成、失败、取消或中断显示本次请求未回传，未知结果显示中性的“已结束未回传”，不把它当作连接故障或建议重扫，不伪造或发送伙伴正文。迟到回传被拒绝，具体错误码见手册。回传正在读取图片或发送时，完成轮询不会打断它。查询失败或完成未知不当成成功；缺少能力时保留 30 分钟超时。查询完成后依次等待 1 秒、5 秒，之后每次等待 15 秒；完成到查询之间仍有窗口，查询慢、失败或权限拒绝会使窗口延长，最长保留原有超时，无法保证同一伙伴桌面轮次调用旧编号会立即被拒绝。插件不读取伙伴历史，不监听桌面答案自动发送；要彻底消除这个工具调用窗口，需要宿主提供每轮输入的身份关联。

## 支持范围

0.3.5 起新增 `send_to_wechat`，用于主人要求主动发微信、通知或提醒的场景，无需当前微信请求。伙伴可省略 `id` 使用自己的绑定；桌面任务先调用 `list_bindings`，再指定 Bot `id`。默认发给该 Bot 最近联系的微信用户，也可从 `runtime.bots[].peers` 中选择 `peer_id`。每个 Bot 保留最近 8 位联系人的最新发送上下文，陌生联系人需先向该 Bot 发消息。文字和图片限制与回传相同，图片走顶层 `attachments`。结果包含实际 Bot 与联系人 ID。普通微信问答仍用 `reply_to_wechat`；无当前请求时提示使用主动发送工具，不自动改走主动发送。

升级后，旧版本保存的登录仍可恢复，但没有联系人上下文，需先从微信发一条消息。新版收到的联系人上下文随登录加密保存，重启后可主动发送。暂停保留上下文，换绑伙伴、退出登录或更换微信账号清除上下文。Bot 卡片出现“更新伙伴说明”时点击一次，或编辑保存绑定，告知伙伴新增用法；升级本身不自动联系伙伴。相同 callId 在进程内不重复发送；重启不恢复发送记录，不提供跨调用或跨重启的发送去重，`DELIVERY_UNCERTAIN` 时先检查微信，不能自动重试。

支持多组配置、独立连接、扫码登录、文字和图片收发、请求编号与回传校验。微信图片由 Node 按腾讯 CDN 协议下载、AES-128-ECB 解密，再通过 Cindy 公开图片附件接口交给伙伴；支持图片单独发送及与文字混合发送。每条最多 4 张 PNG/JPEG/WebP，每张不超过 5 MiB。等待处理的图片共享 40 MiB 预留额度，超额明确拒绝，请稍后重发。伙伴回图通过 `ghost_call` 顶层 `attachments` 交接，`reply_to_wechat` 可省略 text；先上传所有图片，再发送文字和图片。同请求同文字同图片不重发。

语音消息（包括接口附带 `voice_item.text` 的语音）不转交伙伴，插件直接回到原微信用户：“暂不支持语音，请使用微信语音转文字后发送。”。微信转成文字后发送的普通文字消息照常处理。包含语音的混合消息整条拒绝，不部分转交文字或图片。面板显示 `VOICE_UNSUPPORTED`；提示成功计入回复数，语音仍计入拒绝数。同一消息去重，保存接收进度后只尝试发送一次提示；发送结果不确定时显示 `DELIVERY_UNCERTAIN`，不自动重发。不执行原始语音 ASR。

图片在 Node 和沙箱之间按 192 KiB base64 分块交接，遵守 Cindy 0.1.128 的请求/通知体积限制；分块与回传绑定原请求和连接代次，停用或断开清理缓存。

首次登录后，Bot 凭证、接收游标与联系人发送上下文通过 AES-256-GCM 加密保存至 Cindy 插件私有数据目录；密钥自动生成并交给 Cindy 保险库，按声明的方法临时注入 Node。配置、日志、工具结果与模型均得不到 Token 明文；状态只公开联系人 ID 和接收时间。图片下载信息与密钥仅在 Node 内存；交给伙伴的图片进入 Cindy 普通消息附件存储。

正常重启、插件更新或工作进程恢复会读取保存的登录，不需要再次扫码。“停用收发”保留该组登录；“断开”先暂停本组并清理保存记录，成功才完成断开。清理失败会保留当前连接并明确报错；磁盘写入中断可能损坏保存文件，重启后需检查状态，必要时重新登录。删除绑定清除对应配置，后续不会恢复已删除的组。重新生成二维码不会清除旧登录，确认新登录并保存成功后才替换。微信凭证失效、保险库不可用或记录损坏会如实报错。

暂不支持语音收发、文件/视频、额外验证码登录和持久收件箱。包含不支持内容的整条消息会拒绝，避免部分转交。重启前正在处理的微信请求不恢复；保存游标后再投递，避免重启重复回答，但崩溃窗口内尚未投递的消息可能需要用户重新发送。发送结果不确定时不会自动重发。自动测试模拟微信与宿主，不能替代扫码后的真实端到端及完整 Cindy 重启验收。实际验收记录见 `docs/verification.md`。

## 目录与接口

`src/core.mjs` 管理伙伴路由与回传身份；`src/main.mjs` 使用 Cindy 公开接口；`src/worker.cjs` 管理多 Bot 连接；`src/state.cjs` 加解密登录；`src/persistence.mjs` 通过 Host 保险库和私有目录保存状态；`src/ilink.cjs` 实现 iLink 与 CDN 线协议，`src/media.cjs` 处理图片字节与加解密，`src/handoff.mjs` 读取宿主已过户的图片；`src/settings.*` 是设置页。随包用法见 `wechat-companion/manual/getting-started/MANUAL.md`。
