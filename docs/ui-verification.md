# 多 Bot 界面验收（0.3.0 历史记录）

以下为 0.3.0 的历史验收记录，不代表 0.3.2 已完成真实界面验收。0.3.2 的自动测试为 81 项，当前验证范围见 verification.md。

历史版本：0.3.0。宿主 Cindy 0.1.128，官方 tag v0.1.128 对应 commit 9d62b213c960c63daa46996de8a606965f2f2299；设置页沿用该版本的 /wake、BroadcastChannel 和 /kv 接口。

## 已验证

- 构建、生成代码语法检查、71 项自动测试通过。
- 新增创建未绑定伙伴的 Bot，扫码确认且安全保存后再绑定伙伴并自动开始接收。未绑定时保持暂停，不向任何伙伴投递。
- 未选伙伴的登录可在新运行实例恢复；选择伙伴后再次重启仍自动连接，不新增扫码请求。
- 多个待配置 Bot 有独立标识和名称；取消一组不删除其他组。伙伴一对一约束保持生效。
- 在 Cindy 浏览器中运行真实设置页源码与模拟后台：新增按钮直接展示二维码，登录确认后切换到伙伴选择，提交时自动设置聊天状态。
- 已绑定伙伴的单选卡显示归属并禁用；无可用伙伴时提供创建/启用与刷新指引，开始聊天按钮禁用。
- 点击稍后选择保留登录，重新选择伙伴无需生成新二维码。
- 630px 布局显示双列 Bot 卡片；320px 下列表和伙伴卡变成单列，无横向溢出。明暗主题均使用宿主变量，暗色原生控件跟随 color-scheme。

## 仍需真实微信验收

浏览器交互使用模拟扫码结果，不操作真实微信账号。真实扫码、伙伴回答回到微信，以及完整 Cindy 重启后的端到端行为，需安装更新包后实测。本次没有安装或发布插件。
